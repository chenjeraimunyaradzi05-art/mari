## Deliberately NOT quarantined

- **`packages\ui\dist` and `packages\ui\mari-ui-0.1.0.tgz`** — athena-frontend
  consumes `@mari/ui` from both (see its `package.json` and `next.config.js`
  alias). Removing them breaks the build.
- **Root `package.json` / `package-lock.json` / `node_modules`** — root deps
  (bcryptjs, jsonwebtoken, mysql2, speakeasy…) have no obvious consumer, but
  verify nothing imports them before removing. Manual review recommended.
- **`athena-platform\server\uploads\`** — may contain real uploaded files.
- **Active `.env` / `.env.local` / `.env.production` files** in
  athena-frontend, app-backend and athena-platform\server — needed to run.
  **Action instead: rotate every secret in them** (they have lived in a
  OneDrive-synced folder) and consider moving to a secrets manager
  (`athena-platform/server/src/utils/secrets.ts` already supports AWS
  Secrets Manager).
- `node_modules` of the four active projects — needed; reinstallable anyway.

## Duplicate-implementation note (bigger decision than a file move)

The workspace still contains **three parallel implementations** (athena-platform,
athena-frontend + mock-api, app-backend). This overlap is itself flagged in
`ATHENA_GAP_REPORT.md` as a security liability (auth/payments/webhooks exist
in triplicate). Consolidation is a product decision, so nothing was moved —
but once you choose a primary line, this script can be extended to retire the
others the same way.
