ATHENA Outreach — Print Specs

Target print size: US Letter landscape (11" × 8.5")
Bleed: 0.125" (3 mm) on all sides — final art dimensions = 11.25" × 8.75"
Trim: 11" × 8.5" (content should stay within safety margin of 0.25" from trim)
Color profile
- Prepare artwork in RGB but export final PDF with a CMYK conversion if possible in your designer (PowerPoint/Illustrator) for professional print houses.
- Use 300 DPI for embedded raster imagery
Fonts
- Embed fonts in the final PDF (e.g., Inter OTF/TTF) so printed text remains crisp
Crop marks
- Place crop marks outside the bleed area
File naming
- Use clear naming convention and include REV in filenames for print runs (e.g., TurboTax_Outreach_Deck_Final_Print_Bleed_REV1.pdf)

Notes
- The repo contains a 'final print bleed' PDF generated programmatically for review; for production printing, export the PPTX from PowerPoint/Illustrator with embedded fonts and color profile converted to CMYK and include printer-provided marks and bleeds.
