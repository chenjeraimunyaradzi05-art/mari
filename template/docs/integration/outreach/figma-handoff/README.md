Figma Handoff Package — ATHENA × TurboTax Outreach

What this contains:
- svg-artboards/: example SVG artboards (title and content slides) which can be imported into Figma as frames.
- assets/: SVGs/PNGs (logotype, logomark, swatches)
- style-tokens.json: color & typography tokens to import into Figma

How to use:
1. Open Figma and create a new file
2. Import the contents of svg-artboards/ as frames (File → Import)
3. Import the SVGs from assets/ for use as components / logos
4. Use style-tokens.json as a reference to create shared styles (colors and text styles)

Notes
- The artboards are low-fidelity, built for quick handoff. Designers should refine layout, typography and replace placeholders with final imagery.
