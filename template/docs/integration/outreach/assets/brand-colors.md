# ATHENA — Brand Colors

Primary palette
- Primary Teal: #07B8B0
- Deep Teal (accent): #0B7285
- Midnight (background/dark): #071426

Secondary palette
- Coral (accent): #FF8A67
- Soft Mint (muted): #DFF8F6
- Neutral Gray (text): #111827

Usage notes
- Primary teal pair (#07B8B0 / #0B7285) are used for primary CTAs, accents and highlights.
- Use Midnight for dark backgrounds, Neutral Gray for body text. Coral is an accent color for CTAs and highlights only.
- Ensure accessible contrast ratios for UI text and call-outs.
