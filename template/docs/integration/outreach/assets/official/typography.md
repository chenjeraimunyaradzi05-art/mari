# ATHENA Typography Guidelines

Recommended typefaces
- Primary (brand): Inter (variable font) — use for headings & body copy.
- Secondary: Merriweather / Playfair (serif) — optional for editorial headers.

Usage
- Headings: Inter, 700 weight, letter-spacing -0.02em
- Body copy: Inter, 400 weight, line-height 1.45
- Captions & microcopy: Inter, 300 weight, 12px

Fallbacks
- Web-safe fallbacks: system-ui, -apple-system, 'Segoe UI', Roboto, 'Helvetica Neue', Arial

Notes
- When adding to PowerPoint, embed the Inter font file (OTF/TTF) to preserve layout when exporting to PDF.
- For print PDFs, request high-res fonts from design/branding and embed them via the designer tools for production printing.
