ATHENA — Official Brand Pack

This folder contains the official ATHENA brand assets used for the TurboTax outreach deck and prototypes. Files included:
- logomark.svg / logomark.png (square) — primary symbol
- logotype.svg / logotype.png (horizontal version) — wordmark + tagline
- logomark-inverse.svg / logomark-inverse.png — light-on-dark version
- swatches.png — color palette swatches
- typography.md — typography guidelines and recommended fonts

Usage:
- Use the SVGs for Figma / designer import to preserve vectors.
- Use PNGs for web and PPTX imports where required. Use the appropriate size (512 or 256) depending on use-case.
