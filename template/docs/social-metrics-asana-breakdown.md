## Calendar Holds

1. **Co-Design Workshop (90 min)**
   - Participants: PMs, UX, Accessibility, Eng leads, Data partner.
   - Attach PDFs/links of briefs + plan.
   - Include Zoom/Meet link and collaborative whiteboard link.
2. **Prototype Review (30 min)**
   - Scheduled next business day to walk through low-fi prototype.
   - Optional if async feedback sufficient; keep hold as contingency.
3. **Pilot Validation Sessions (2 × 30 min)**
   - Invite mentors/members separately; include NDA reminder if needed.
4. **Sign-Off Checkpoint (30 min)**
   - PM, UX, Eng leads review validation outcomes and approve build readiness.
5. **Engineering Kickoff (45 min)**
   - Held after sign-off; cover API contracts, test strategy, timelines.
