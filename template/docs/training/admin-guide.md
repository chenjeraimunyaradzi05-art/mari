# Admin Training Guide

## Module 1: User Management

### Reviewing Gender Verification Requests

1. Navigate to Admin > Gender Verification Queue
2. Review AI assessment + confidence score
3. Check signup data: name, email domain, profile text, photo
4. Decision options:
   - **Approve**: Grant full member access
   - **Approve as Provider**: Grant employer/provider access only
   - **Request More Info**: Ask for additional verification
   - **Reject**: Block signup with reason

**Red Flags**:

- Generic email domains with male-typical names
- Profile photos showing men
- Business email domains (likely employers)
- Inconsistent profile data

### Managing User Roles

1. Navigate to Admin > Users
2. Find user, click "Edit Roles"
3. Available roles:
   - Member (default for women)
   - Employer
   - Mentor
   - TAFE/University
   - Real Estate Provider
   - Trades Organization
   - Financial Service Provider
   - Public Sector

4. Save changes
5. User receives notification of role change

## Module 2: Content Moderation

### Reviewing Flagged Posts

1. Navigate to Admin > Content Moderation
2. Filter by: AI Flagged, User Reported, All
3. Review post content + context
4. Check user history (previous violations)
5. Decision options:
   - **Approve**: Remove flag, post stays
   - **Edit**: Remove violating content
   - **Hide**: Remove from public feeds
   - **Delete**: Permanently remove
   - **Ban User**: Suspend user account

**Policy Violations**:

- Harassment or hate speech
- Spam or scams
- Explicit sexual content
- Misinformation (health, financial, safety)
- Male users in member-only spaces

### Moderating Media Uploads

1. Navigate to Admin > Media Moderation
2. Review flagged images/videos
3. Use same decision framework as posts
4. Note: AI vision model pre-screens all uploads

## Module 3: Dashboard Analytics

### Key Metrics to Monitor

- **Active Users**: Daily/weekly/monthly active
- **Engagement Rate**: Posts, comments, connections per user
- **Pathway Completion**: % of users completing pathway phases
- **Job Applications**: Applications per posting, success rate
- **Revenue Metrics**: Advertising revenue, partnership commissions
- **Churn Risk**: High-risk users flagged by predictive model

### Creating Reports

1. Navigate to Admin > Analytics
2. Select report type:
   - User Growth
   - Engagement Trends
   - Impact Metrics (jobs secured, income uplift)
   - Revenue Dashboard
3. Set date range
4. Export as PDF or CSV

## Module 4: Security Incidents

### Responding to Security Alerts

1. Check Admin > Security Dashboard
2. Alert types:
   - Suspicious Login (new device/location)
   - DLP Violation (PII in post/message)
   - Rate Limit Breach (potential bot)
   - Unauthorized Access Attempt

3. Investigation steps:
   - Review user activity timeline
   - Check associated IP addresses
   - Review recent content/messages
   - Look for patterns (multiple accounts)

4. Actions:
   - Flag for Review
   - Temporary Suspension (pending investigation)
   - Permanent Ban
   - Escalate to Security Team

### Data Breach Response

**If user reports potential breach**:

1. Immediately escalate to Security Lead
2. Do NOT investigate on your own
3. Document: User report, timestamp, details
4. Follow Incident Response Runbook
