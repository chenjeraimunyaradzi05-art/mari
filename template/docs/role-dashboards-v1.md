# Role Dashboards v1 — Implementation Summary

Status: Completed (code + tests) — Increment 3 (10–15%)


## Overview

This document summarizes the repository changes that deliver Role Dashboards v1: role-based controllers/views, RBAC, demo seed data, KPI widgets wired to live sources, and test coverage.

## What I changed / added

- Registered a new 'member' persona so the roadmap "Member" naming is supported alongside "candidate".
  - config/dashboard_roles.php: added `member` role mapping (same widgets as `candidate`).
- RBAC policy normalization so `member` and `candidate` are treated as synonyms.
  - app/Policies/RoleDashboardPolicy.php: normalized role handling for access checks and feature flags.
- Tests:
  - tests/Feature/Dashboard/RoleDashboardMemberAliasTest.php: new tests asserting member/candidate alias behavior.
  - tests/Playwright/role-dashboard-member.spec.js: added browser tests for `member` role access (guest & seeded admin checks).

## How KPI tiles are populated

- KPI widgets are resolved server-side in: `App\Services\Dashboards\RoleDashboardService`.
  - Widgets pull live data from Eloquent models, domain services (BusinessInsightsService, CareerIntelligencePulseService, RealTimeAnalyticsEngine, etc.) and return DTOs used by the role view.

## Tests & QA

- PHP Unit + Feature tests were run and passed locally for dashboard-related tests.
- New Playwright tests were added for browser-level access control checks; run these in your CI environment to validate browser flows.

## How to try locally

1. Seed demo data (creates `demo+member@athena.test` and many role demo users):

```bash
php artisan db:seed --class=RoleDashboardsDemoSeeder
```

1. Visit a role dashboard (after login) — examples:

- `/dashboards/role/member`
- `/dashboards/role/candidate`
- `/dashboards/role/company`

1. Run tests locally:

```bash
# PHPUnit
php artisan test --testsuite=Feature tests/Feature/Dashboard

# Playwright (if configured in your environment)
npx playwright test tests/Playwright/role-dashboard-member.spec.js
```
