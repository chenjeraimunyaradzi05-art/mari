# TurboTax Integration for ATHENA

This folder contains the initial deliverables for integrating TurboTax (Intuit) into the ATHENA platform.

Included docs:
- `business-proposal.md` — formal partnership/proposal overview for Intuit/TurboTax
- `technical-architecture.md` — recommended architecture for API-level integration and data flow
- `roadmap.md` — implementable next steps, milestones, owners, and timeline

Purpose
------
These artifacts are intended to quickly capture the strategic, technical and implementation steps to take TurboTax from idea to pilot inside ATHENA. They are intentionally scoped to be practical and actionable for a small cross-functional team.
