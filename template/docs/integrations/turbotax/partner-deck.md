# ATHENA x TurboTax — Scoping Deck (3 slides)

Slide 1 — Opportunity (headline)
- ATHENA = Life Operating System for Women
- Reach: engaged women entrepreneurs, 9 personas — Business Owners, Members with side income, Realtors
- Problem: fragmented tools (accounting, formation, taxes) — users switch contexts and lose data
- Opportunity for TurboTax: integrated flows + new, high-quality filers

Slide 2 — Pilot approach (technical + commercial)
- Phase 1 (6 months): Read-only projections for a single persona (Business Owner)
  - Sandbox integration, per-user OAuth, pilot cohort 50–200
- Phase 2: Optional sandbox file/e-file pilot + extension to other personas
- Commercial asks: sandbox access, developer liaison, pilot contract (referral / revenue share)

Slide 3 — Success metrics & timeline
- Pilot KPIs: connectivity rate, net promoter feedback, projection -> file conversion %
- Timeline: discovery (2–6 weeks) → pilot implementation (3–6 months) → e-file expansion (3–6 months)
- Next step: 30–60 min scoping call with dev relations + partnerships + legal
