# GDPR Compliance Checklist

## Data Access & Portability
- [x] Export user profile, posts, messages, and settings into JSON/ZIP.
- [x] Include export request audit log.

## Right to be Forgotten
- [x] Soft-delete user account, anonymize references.
- [x] Cascade deletion for personal identifiers.

## Consent & Preferences
- [x] Record consent timestamps for email/push/in-app.
- [x] Provide preference center with audit trail.

## Security
- [x] Encrypt sensitive data at rest.
- [x] Log access to personal data.

## Operational
- [x] Add DPA and breach notification procedure.
- [x] Keep data retention policy updated.
